# lab-media

Heavy, self-contained modules and media for the Psychedelics & Contemplation Lab websites,
served by GitHub Pages (planned domain: media.psychedelicsandcontemplationlab.com).
The site repositories only link here, so their own builds stay small.

| Path | What | Source |
|---|---|---|
| `montreal-model/module-1/` | The Montreal Model – Module 1 (interactive HTML5 training module, ActivePresenter export, 41 MB with audio) | "MM Module 1 - HTML5 Ver2 (click fix)" |

Rules: no video or files above 100 MB in git; keep each module in its own folder with its own `index.html`.
